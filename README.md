# ✈️ Travel Explorer

Travel Explorer is a responsive front-end project built to practice HTML, CSS, Bootstrap 5, and responsive web design.

The website helps users discover travel destinations, explore categories, get travel inspiration, and plan future adventures through a modern and user-friendly interface.

---

## 🌍 Features

- Responsive Navigation Bar
- Hero Banner with Search Section
- Popular Travel Categories
- Featured Destination Section
- Top Destinations Grid
- Travel Inspiration Progress Bars
- Travel Planner Form
- Traveler Reviews
- Newsletter Subscription Section
- Responsive Footer
